# CloverGo 开源验收记录

验收日期：2026-11-01。发布版本 **0.2.0**，Windows amd64、Go 1.26.5。使用独立 SQLite、专门编写的公开演示材料和真实方舟服务；未使用私人资料，未调用微信推送或发布。本记录不代表所有平台、模型或账号的兼容性保证。

## 发布判断与定位

可作为 **MIT 实验性开源版本**发布。主流程是资料归档、带原文证据的知识提炼、检索、问答与公众号草稿创作。适合个人创作者和开发者；目前以 Windows 本机使用为验收范围。

仓库一句话介绍：

> CloverGo：把个人资料变成有出处的知识，再用于问答与公众号创作。Go 单程序、SQLite 本机存储、内嵌中英双语界面，使用用户自有的火山方舟账号。

首发说明示例：

> 我把自己整理资料和复用知识的流程做成了 CloverGo，并以 MIT 协议开放源码。导入 Markdown、TXT、DOCX 后先生成摘要归档，需要时再提炼知识，每条知识保留可核对的原文出处。基于这些资料，可以检索、与只读 Agent 对话，也可以生成和编辑公众号长文或图文帖草稿。程序在本机运行，AI 功能调用用户自己的方舟账号。当前仍是实验版本，欢迎从资料整理和草稿创作这两个场景试用。

适合强调的卖点：

- **资料可以继续复用**：归档、提炼、查询、创作在一个工具中完成。
- **知识可回看出处**：连续原文片段与字符位置由代码校验，方便人工复核。
- **部署简单**：一个 Go 程序内嵌界面，无需单独部署前端、数据库服务或 Docker。
- **创作有现成出口**：长文章、图文帖、人工编辑、ZIP 导出，可选公众号接入。
- **实现便于研究与二次开发**：只读工具循环、检索融合、证据校验、Prompt 版本与运行记录都有具体实现。

不使用“完全离线”“数据不出本机”“零幻觉”“跨语言必定命中”“自动运营/自动发布”等宣传。AI 编程参与方式可以作为开发背景，不替代产品价值。

## 脱敏范围与限制

- 检查当前源码、暂存区及公开引用可达对象；扫描本机已知密钥值、常见 token/私钥形态、带凭据 URL、本机路径和危险文件名。公开历史只有一个无父提交的 `Initial Commit`，标签为 `v0.2.0`。
- 未命中已知真实密钥或私钥；URL 命中项为 `user:password` 等文档/UI 占位示例。没有发现被跟踪的 `.env`、SQLite、私人媒体或运行输出。
- 当前文档的机器私有路径已移除，旧提交和旧标签不再保留。提交作者与提交者使用项目通用身份，不包含本机操作者的个人姓名或邮箱。
- `.env`、`data/`、`.local/`、日志、演示数据库、运行结果和本机二进制仍留在 Git 忽略范围。不要直接压缩整个工作目录作为源码发布包。
- 这是定向扫描与实际流程验收，不是完整渗透测试，也不能保证不存在未知形式的敏感信息。

## 明确保留的限制

- **跨语言召回需要继续改进**：本次英文相关问题没有检出中文知识。未为让样本通过而调低语义阈值，首版不以此作为核心卖点。
- **微信推送/发布仍是部分验证能力**：本次没有使用真实公众号重新验收，不把生成草稿成功等同于推送成功。代码仅记录发布提交结果，不追踪最终发布状态。
- **不是离线 AI 或多用户服务**：资料落本机，相关内容发送方舟；锁屏不加密文件，也不支持公网部署。
- **图片不是 AI 生成**：使用上传图片或本地标题卡片，未上传图片时部分推送路径依赖本机光栅化工具。
- 本次未验证 Linux/macOS 的运行与打包，也未给出大规模知识库的速度或召回质量结论。
